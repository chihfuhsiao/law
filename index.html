使用說明與更新方式

查詢

  • 左側選擇土管（或選「全部土管」跨檔搜尋），在上方輸入關鍵字。
  • 多個關鍵字用空白分隔，條文須同時包含全部關鍵字才會列出（例：退縮 騎樓）。
  • 用 | 表示「或」，任一個符合即可（例：綠美化|綠化、停車位|停車空間 獎勵）。
  • 「常用」按鈕會帶入預設的關鍵字組合；按鈕內容可在本檔案的 QUICK 設定中增減。
  • 結果依條文順序排列；勾選「只顯示相關段落」時只列出含關鍵字的段落，點標題列可展開全文。
  • 「台／臺」、全形／半形、空白都視為相同，例如 台中 可找到「臺中」，32條 可找到「第32 條」。
  • 按「開啟 PDF」會在新分頁開啟原始檔並跳到該條文所在頁。有框線的表格會以表格呈現；沒有框線或排版特殊的表格可能只顯示文字，數值請以 PDF 原檔為準。

一次下載整頁土管 PDF（瀏覽器主控台）

網站每個都市計畫區頁面有數十個 PDF，可用 Chrome／Edge 的主控台（Console）一次全部下載：

  1. 用 Chrome 或 Edge 開啟上方「土地使用管制彙總」網址，點進要下載的都市計畫區（例：臺中市都市計畫）， 確認畫面上看得到「檔案下載（或附件）」底下的 PDF 清單。不要點進個別 PDF 或圖片，要停在清單頁。
  2. 按 F12 開啟開發者工具，切換到 Console（主控台） 分頁。
  3. （可先檢查）貼上下面這行按 Enter，會列出這頁抓得到的 PDF 清單與數量： 
    console.table([...document.querySelectorAll('a[href]')].filter(a=>/\.pdf/i.test(a.href)).map(a=>({名稱:a.innerText.trim(), 網址:a.href})))
  4. 點「複製下載指令」，貼到主控台按 Enter： 
    (async () => {
  const seen = new Set();
  const items = [...document.querySelectorAll('a[href]')]
    .filter(a => /\.pdf(\?|$)/i.test(a.href) || /\.pdf\s*$/i.test(a.innerText.trim()))
    .filter(a => !seen.has(a.href) && seen.add(a.href));
  console.log(`共 ${items.length} 個 PDF，開始下載…（下載期間請勿關閉或切換此頁）`);
  const fail = [];
  for (const [i, a] of items.entries()) {
    let name = a.innerText.trim().replace(/[\\/:*?"<>|]/g, '_');
    if (!/\.pdf$/i.test(name)) name += '.pdf';
    try {
      const res = await fetch(a.href);
      if (!res.ok) throw new Error(res.status);
      const blob = await res.blob();
      const url = URL.createObjectURL(blob);
      const link = document.createElement('a');
      link.href = url; link.download = name;
      document.body.appendChild(link); link.click(); link.remove();
      setTimeout(() => URL.revokeObjectURL(url), 10000);
      console.log(`✅ ${i + 1}/${items.length} ${name}`);
    } catch (e) {
      console.warn(`❌ ${i + 1}/${items.length} ${name}`, e);
      fail.push(name);
    }
    await new Promise(r => setTimeout(r, 1000));
  }
  console.log(`完成！失敗 ${fail.length} 個`, fail);
})();
  5. 瀏覽器詢問「此網站要下載多個檔案」時選 允許（若誤按封鎖：點網址列左側圖示 → 網站設定 → 自動下載改為允許，再重跑一次）。
  6. 主控台會逐一顯示 ✅ 進度，最後一行顯示失敗清單（正常為 0 個）。檔案存到「下載」資料夾，檔名即網頁上的名稱。
  7. 把需要的 PDF 移到本資料夾，再執行下方「更新步驟」。

注意： ① 若 Chrome 擋下貼上，畫面會出現黃色警告，先在主控台輸入 allow pasting 按 Enter，再貼一次。 ② 主控台出現網站本身的紅色錯誤（例如 jQuery…）不影響下載。 ③ 每個都市計畫區頁面要分別進去執行一次。

更新步驟

  1. 從上方網址下載新的或已修正的土管 PDF（可用上面的主控台指令一次下載）。
  2. 放進本資料夾（與 土管查詢.exe 同一個資料夾，可再分子資料夾）。 若是同一份土管的新版本：直接覆蓋同名檔，或把舊檔移到 _舊版 資料夾（名稱以 _ 開頭的資料夾不會被掃描）。
  3. 按左上角「重新掃描資料夾」（或重新執行 土管查詢.exe，啟動時也會自動掃描）。 只會重新處理新增或有變動的 PDF；完成後頁面會自動重新整理。
  4. 掃描後 PDF 原檔會一併存進儲存檔，之後就算資料夾裡沒有這個 PDF，仍可查詢與開啟。
  5. 要淘汰某份土管：先把資料夾裡的那個 PDF 刪除或移到 _舊版，再到查詢頁選那一份，按標題下方的「從系統移除」。
  6. 最近一次新增或更新的土管會標示 新。

檔名建議保留網站上的編號開頭（例：1-20變更臺中市…），清單會依編號排序並自動歸到對應的都市計畫區。新的都市計畫區名稱可在下方「進階設定」補上，不需重新編譯。

系統檔案

  • 土管查詢.exe：本系統唯一的執行檔（查詢頁面、索引、說明都在裡面），不需安裝 Python。雙擊執行，使用期間保持黑色視窗開著，關閉視窗即結束。旁邊的 _internal 資料夾是執行檔的支援檔，必須和它放在一起，請勿刪除或改名。
  • 土管查詢.db：儲存檔，包含所有土管 PDF 原檔、索引、擷取的圖片、參考圖、設定與更新紀錄。請妥善備份；刪除後只能從資料夾內現有的 PDF 重建。
  • 各份土管 PDF：掃描進系統後就不一定要留在資料夾；要新增或更新時再放進來掃描即可。
  • 若資料看起來不對，可按住 Shift 再按「重新掃描資料夾」＝全部重新解析。
  • 遇到亂碼字型（清單出現 ⚠「部分文字為亂碼」）時，系統會先自動推算；推算不出來再到下方「進階設定」補上規則。
  • 原始碼 土管查詢.py 建議另存（例如放在 _原始碼 資料夾，不會被掃描）。修改後執行 python 土管查詢.py --build-exe 即可重新編譯出 土管查詢.exe。

在其他電腦使用

  1. 把 土管查詢.exe、_internal 資料夾和 土管查詢.db 一起複製到另一台電腦的同一個資料夾。
  2. 雙擊 土管查詢.exe 即可使用，不需要安裝 Python，也不需要土管 PDF 檔。
  3. 在那台電腦新增土管時，把 PDF 放進同一個資料夾，按「重新掃描資料夾」即可存進該台的儲存檔。

遇到無法辨識的新 PDF 時

  • 亂碼字型（搜尋不到、清單出現 ⚠「部分文字為亂碼」）：系統會自動推算華康 ETen 字型的換算規則並記在「更新紀錄」。 推算不出來時，請把該 PDF 交給維護人員取得規則（例如 {"字型名稱": {"sym": 499, "han": 436}}），貼到下方「亂碼字型規則」儲存，系統會自動重新解析。
  • 條文切不出來（⚠「無法辨識條文編號，改以頁為單位切分」）：內容仍可搜尋，只是以「頁」為單位顯示，並可開啟 PDF 對照。 若要改善切分方式，需修改原始碼後重新編譯。
  • 掃描圖檔（⚠「幾乎沒有文字層」）：PDF 只有圖片沒有文字，系統無法搜尋。可先用 Adobe Acrobat 等軟體做「文字辨識（OCR）」另存後，放回資料夾重新掃描。
  • 新的都市計畫區：清單顯示「編號 N-」時，到下方「都市計畫區名稱」補上名稱即可。

參考圖（範圍示意圖等）

  • 把圖檔（.jpg／.png，例如「臺中市都市計畫-主要計畫暨細部計畫-範圍示意圖.jpg」）放進本資料夾，按「重新掃描資料夾」，左側篩選欄下方就會出現同名按鈕，點擊即可開啟查看。
  • 圖檔會一併存進儲存檔；按鈕名稱＝檔名。要移除時，先刪除資料夾裡的圖檔，再打開該圖按「從系統移除此圖」。
